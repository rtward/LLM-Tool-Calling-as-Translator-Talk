# LLM Tool Calling
## Or: Your Computer's Universal Translator

This repository contains the slides and demo code for a talk given at Phreaknic 26 in Nashville, TN.

The gist of the talk is that while I have some skepticism that "AI" (large language models that is) is going to radically transform the world, I think that conceiving of LLMs as a translation layer between the real world and computers yields some really interesting use cases where the LLMs seem to perform very well.
